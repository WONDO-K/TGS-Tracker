# 전달 시안 적용 계획 · 2026-10-29

사용자가 전달한 `TGS-Tracker-design-handoff.md`와 21개 화면 HTML 시안을 시각 기준으로 사용한다. design-taste-frontend 앱 화면 흐름을 적용하되 사용자가 지정한 IBM Plex 글꼴·상태 4색·코랄 경고·흰 사이드바·둥근 반경을 우선한다. 기존 데이터/RLS/RPC 계약과 GitHub Pages 구성을 바꾸지 않는다.

1. 시안의 토큰, 로고, 236px 사이드바, 1000px 이하 하단 탐색을 기존 화면에 적용한다.
2. 미반영 요약·현재 필터 기준 상태 분포·배포 필터 칩·TEST/PROD 진행선을 실제 조회 데이터에 연결한다. 모바일 칸반은 상태 탭으로 한 열씩 확인한다.
3. 기존 폼·관리자 화면을 공통 토큰으로 맞추고 상태 선택, 안전한 확인 모달과 이미지 확대를 연결한다.
4. 모바일 메뉴·상태 탭·기존 필터와 쓰기 흐름을 브라우저에서 검증한다. 실무·데모 빌드와 실제 배포 빌드 1440/768/390px 화면을 확인한다.

사용성 보정: 10자 비밀번호 기준 유지, 옅은 라벨 대비 강화, 비활성 항목을 35% 투명도로 흐리지 않음, 44px 조작 영역, 긴 제목을 잘라 정보가 사라지게 하지 않음, 필터/미저장 입력 보존. 위험 작업과 관리자 승격은 결과를 명시하며 승격은 동의 체크 후 실행한다. 시안의 정적 수치와 이름은 하드코딩하지 않는다.

새 패키지·UI 프레임워크는 추가하지 않는다. 공개 데모는 계속 읽기 전용이며 소개 페이지는 업무 서비스와 별도 범위로 둔다. 커밋·push·외부 배포는 수행하지 않는다.

## 적용 결과

- 시안의 로고, IBM Plex 글꼴, 흰 사이드바, 상태 4색과 운영 미반영 코랄을 적용했다. 보드·목록·상세·등록·로그인·내 계정·관리자 화면이 같은 토큰을 사용한다.
- 미반영 요약, 상태 분포, 배포 필터와 TEST/PROD 진행선은 기존 API 결과를 사용한다. 집계는 화면에 먼저 불러온 30개 카드의 수로 대체하지 않는다.
- 모바일은 하단 탐색과 단계별 단일 열을 사용한다. 390px에서도 네 단계가 모두 보이며 방향키·Home·End로 선택할 수 있다. 상세의 배포 요약을 폼보다 먼저 배치했다.
- 상태는 2×2 버튼으로 선택하고 기존 저장 버튼으로 확정한다. 배포 반영일 초기화·첨부 삭제·보관·접근 차단은 취소 가능한 확인 창을 사용한다. 관리자 승격은 전체 고객사 접근 동의 체크가 필요하다.
- 첨부 이미지는 확대 창에서 확인하고 Escape로 닫는다. 리뷰에서 발견한 썸네일 높이 상속과 801–1000px 메뉴 위치 문제를 수정하고 브라우저 회귀 검증에 포함했다.

## 검증과 범위

- `npm test`: 16개 통과. PGlite로 기존 DB/RLS/RPC 권한 계약 포함.
- `npx playwright test`: 9개 통과. 미저장 본문 유지, 120건 페이징, 부분 업로드 재시도, 이미지 실제 확대, 모바일 탭·키보드 이동, 반영일 초기화 취소, 승격 동의, 필터·복귀, 태블릿 메뉴, 관리자 표를 검증했다.
- `npm run build`, `npm run build:demo`: 타입 검사 및 빌드 통과.
- 정적 데모 보드·목록·상세를 1440/768/390px로 검사했다. 각각 inspector 0 FAIL. 등록·상세·고객사·사용자·내 계정은 가상 API를 연결한 브라우저에서 1440/900/390px 캡처와 가로 넘침 검사를 수행했다. 로그인 데스크톱도 확인했다.
- 정적 lint 0 FAIL, 21 WARN. 앱 화면에서 허용되는 숫자용 모노, 날짜 패딩, 폼 구역 라벨, 시안의 약한 그림자와 실제 오버레이 그림자를 유지했다. inspector의 작은 글자 경고는 번호·날짜·보조 라벨의 11–12px 서식이다. 주요 제목과 입력 본문은 더 크게 유지했다. 높이 차이 경고는 요청 수가 다른 칸반 열과 본문/보조 패널의 차이로 유지했다.
- 실제 Supabase 프로젝트 로그인·SMTP 발송·운영 저장소 연동은 이번 가상 API/로컬 DB 검증 범위에 포함하지 않는다. 데이터베이스와 배포 워크플로는 변경하지 않았다.

Top three problems and fixes:

3. 이미지 확대 높이와 태블릿 메뉴의 기존 CSS 상속을 수정했다. 테스트에서 실제 이미지 크기와 메뉴 좌표를 검증한다.
