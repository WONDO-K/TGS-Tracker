# 요청 현황 Excel 내보내기

승인된 범위: 현재 고객사·검색·배포·작성자·요청일·보관 필터에 맞는 전체 요청을 .xlsx로 다운로드한다. 문서/PDF 출력은 후속이다.

1. 기존 list_requests RPC를 100건씩 조회해 전체 목록을 모은다. 화면의 페이지/모바일 상태 탭은 내보내기 범위를 제한하지 않는다. 중간 실패 시 부분 파일을 내려받지 않는다.
2. 요청 현황 시트에 번호·고객사·제목·요청 내용·요청자·요청일·작성자·진행 상태·조치 요약·배포 필요 여부·배포 현황·테스트/운영 반영 시각(한국 시간)·최근 수정 시각·보관 여부를 제공한다. 추출 조건 시트에 필터·추출 시각·건수를 명시한다. 이미지·내부 활동 메모·인증 정보는 제외한다.
3. write-excel-file을 다운로드 시에만 불러와 실제 .xlsx를 생성한다. 사용자 텍스트는 수식이 아닌 문자열로 기록한다. 첫 행 고정·열 너비·자동 필터·줄바꿈을 제공한다. 별도 서버나 파일 저장소는 추가하지 않는다.
4. 보드/목록 툴바에 엑셀 다운로드 버튼을 추가한다. 중복 실행 방지, 진행·실패·빈 결과 안내를 제공한다. 데모는 가상 데이터 다운로드만 허용한다.
5. 실제 생성한 파일을 다시 읽어 한글·줄바꿈·수식 형태 텍스트·날짜·전체 건수를 검증한다. 브라우저에서 필터 전달·100건 초과·다운로드·실패/빈 결과를 검증하고 모바일 툴바를 확인한다.

변경 파일: src/lib/request-export.ts, src/features/requests/ExportRequests.tsx, Board.tsx, handoff.css, package.json/package-lock.json, tests/request-export.test.ts, tests/browser.spec.ts, README 및 작업 현황 문서. DB·서버·배포 설정은 변경하지 않는다.
